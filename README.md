# 遗星志 · Palimpsest

一个由种子生成的螺旋星系考古游戏。

约一千个恒星系沿旋臂分布，数十个文明在其中推演了三千年的历史：崛起、殖民、接触、通商、结盟、背约、战争、称臣、分裂、消亡。你作为探索者在星系间航行，勘测遗迹，把散落各处的记录拼回带因果关系的编年史。仍然存续的文明会在你探索期间继续演化。

**在线游玩：** https://ssychina7273-sys.github.io/palimpsest/

## 玩法

- 在星图上点选星系，再点「航行至此」。拖动平移，滚轮或双指缩放。
- 带金色 ◆ 的星系有未勘测的遗迹，到达后在行星列表里「勘测」。
- 「编年史」按时间排列已复原的记录，并标出每件事的起因。
- 「文明」页记录已识别的文明和其中留名的人物，底部的物种图鉴收录 26 个物种。
- 输入框里的种子决定整个星系。同一个种子，所有人看到的星系都一样。

## 历史里有什么

- **文明之间的关系**：多数文明诞生在别的文明附近，探测范围重叠就会接触。它们通商、结盟、传教、窃取技术；开战时盟友和宗主会被卷入，也可能背约。战败的一方可能割地，可能称臣，日后又可能起兵。每场战争都有名字。
- **先来者与后来者**：约三成文明崛起得晚。先到的邻居按自己的取向行事：只在暗处观察，带来技术，或者直接收为附庸。
- **殖民地的用途**：定居点、矿场、采集站、转运港、观测站、边境要塞、隐修地、流放地、瘟疫后的安置点。用途由当时的处境决定，起因也因此不同。
- **人物**：君主、统帅、先知、学者以各自文明的语言命名，寿命按物种计算。有的物种只记代数或编号，有的不为个体留名。
- **奇观与圣物**：奇观可能毁于战火或易主；圣物会被夺走、陈列、夺回，或者留在废墟里等后来者发掘。
- **天灾**：超新星、红矮星耀斑、小天体撞击、母星气候失衡。行星现在的气候未必是它原来的气候。

## 技术说明

- 单个 HTML 文件，无需服务器，无需构建。
- 全部内容由确定性伪随机数生成：恒星类型 → 轨道温度 → 大气 → 气候 → 宜居性 → 能在此诞生的物种。
- 历史以 50 年为一步推演，事件由条件触发并记录起因；每个种子约有 400 到 800 条历史记录，50 余种事件。
- 探索期以 10 天为一步继续推演十年，节奏与历史相称：多是勘测、会谈、边境摩擦，偶有战争。
- 推演和文本各用一套随机数序列，改写描述不会改变历史本身。
- 进度保存在访客自己浏览器的 localStorage 中。

## 名字

Palimpsest 原指被刮去旧字、重新书写的羊皮纸，底下仍隐约留着旧字的痕迹。
